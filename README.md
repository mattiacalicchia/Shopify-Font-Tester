# Shopify Font Tester – by Mattia Calicchia

A lightweight, single-page tool to test typography choices across:
- **Common fonts** (shared across the entire website)
- **Theme fonts** (available only in the Shopify theme)
- **Mail fonts** (safe fonts supported by major email clients)

**Live demo target (theme reference):** https://themes.shopify.com/themes/madrid/presets/madrid  
**Author:** Mattia Calicchia — https://www.linkedin.com/in/mattiacalicchia/

---

## Accessibility disclaimer (best practices)
Typography impacts readability and accessibility. As a baseline:
- Use highly legible fonts and regular weights for body text
- Minimum recommended size: **16px** on web
- Ensure sufficient **contrast** between text and background
- Avoid decorative fonts for long-form content
- Email clients support a limited set of fonts — always define safe fallbacks

Learn more: WebAIM – Fonts and Accessibility  
https://webaim.org/techniques/fonts/

---

## How to use
1. Open `index.html` in your browser (double click).
2. Pick a font from:
   - **Common font** (site-wide defaults)
   - **Theme font** (theme-only, brand/system fonts)
   - **Mail font** (email-safe fonts)
3. Adjust **font size** and **text color**.
4. Edit the sample text and see the preview update instantly.

**Priority order:** Mail font → Theme font → Common font
