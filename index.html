Preview limitations & font support notice
This tool loads external fonts only when they are publicly available and legally distributable (for example via Google Fonts).

Some fonts listed in the selectors (such as Segoe UI, Futura, Gill Sans, Rockwell) are system fonts or proprietary fonts and cannot be reliably embedded as web fonts without an appropriate license.

If a selected font is not available in your environment, the preview will display the closest fallback font instead. This behavior reflects real‑world conditions in browsers, Shopify themes, and email clients.

Learn more about font accessibility: WebAIM – Fonts and Accessibility
