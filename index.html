Font accessibility best practices
• Use highly legible fonts with regular weight for body text
• Recommended minimum size: 16px on web
• Ensure sufficient contrast between text and background
• Avoid decorative fonts for long-form content
• Email clients support only a limited set of fonts — always define safe fallbacks

Learn more: WebAIM — Fonts and Accessibility
Common font: fonts shared and used across the entire website.
Theme font: fonts available only within the website theme.
Mail font: fonts supported by major email clients (Outlook, Gmail, Apple Mail).
Priority order: Mail font → Theme font → Common font.
